== INDICADORES DE FALHA ==

❌ "Port scan timeout reached"
   → Problema com startup rápido
   → Verificar backend/main.py existe
   
❌ "ModuleNotFoundError"
   → Dependências não instaladas
   → Render build falhou
   
❌ "FileNotFoundError: models/sniper_pro_gen_6.zip"
   → Modelo não foi feito upload
   → Usar Dojo para enviar novo modelo
